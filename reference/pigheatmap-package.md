# pigheatmap: Performance Heatmaps for Swine Production Data

Aggregates production records (e.g. litter size by parity and month) and
draws annotated heatmaps with rich-text cell labels, optional faceting,
sample-size based transparency, and segmented colour scales for traits
that have empirical optimal ranges (parity, backfat, age at first
mating, ...).
